# ============================================================================
# INSTALLATION INSTRUCTIONS
# ============================================================================
# 
# Required Python Version: 3.11.12
# 
# Step 1: Create virtual environment
#   python -m venv .venv
# 
# Step 2: Activate virtual environment
#   Windows:    .venv\Scripts\activate
#   Linux/Mac:  source .venv/bin/activate
# 
# Step 3: Install PyTorch first (before other dependencies)
#   For CUDA GPU support (recommended):
#     pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#   
#   For CPU-only:
#     pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cpu
# 
# Step 4: Install remaining dependencies
#   pip install -r requirements.txt
# 
# Step 5: Download NLTK data (required)
#   python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet')"
# 
# ============================================================================
# NOTES
# ============================================================================
# - Install PyTorch FIRST before other packages to ensure correct CUDA version
# - bitsandbytes requires CUDA; skip for CPU-only installations
# - For GPU: Ensure CUDA 12.1 or compatible version is installed
# - faiss-cpu can be replaced with faiss-gpu for GPU acceleration
# - All retrievers (BM25, Dense, E5, Word2Vec, ColBERT) are included
# - All generators (BasicRAG, MultiTurnRAG, AgenticRAG) use LangChain/LangGraph
# - Fine-tuning (finetune_qwen.py) uses LoRA with 8-bit quantization
# - Evaluation (evaluate.py), inference (main.py), and web UI (web_ui.py) included
# ============================================================================
